# 주술결전 카드 듀얼

HTML 파일 하나로 실행되는 1:1 카드 배틀 게임입니다. (팬메이드 비공식 게임)

## 실행

- **사이트에서 실행 (GitHub Pages)**: 사이트 첫 화면의 [주술결전 카드 듀얼] 또는 `…/jjk_duel/` 주소로 엽니다. 게임 파일을 고칠 때는 PR → 머지만 하면 사이트에 반영됩니다.
- **파일로 실행**: `index.html`을 크롬·엣지에서 직접 열면 됩니다. 연습 대전·카드 설정·튜토리얼은 바로 쓸 수 있습니다.
- 휴대폰은 가로 화면을 권장합니다.

## 게임 모드

| 모드 | 설명 |
|---|---|
| QR로 친구 초대 | 버튼 한 번으로 온라인 대전 방을 만들고 초대 QR을 띄움. 친구가 휴대폰 카메라로 찍으면 그 방에 참가 |
| 연습 대전 | AI와 대전 |
| 온라인 대전 | GitHub PR·머지로 대전 기록을 주고받는 1:1 대전. 방 코드로 참가, 난입·관전 차단, 턴 잠금, 턴 제한시간 150초 |
| 카드 설정 | 15장 이상으로 덱 구성 (같은 카드 중복 불가) |
| 튜토리얼 | 규칙, 궁극기 조합, 시너지, 마허라 소환 조건, 온라인 대전 방법 |

## 주요 규칙

- 체력 80, 생명 2개. 본체 체력이 0이 되면 생명 -1 후 체력 회복
- 턴마다 메인 행동 1번(공격), 서브 행동 2번(뽑기·배치·마법)
- 필드: 메인(유닛) 1칸, 서브(서브·겸용 카드) 1칸, 대기 4칸
- 범위 공격은 상대 메인·서브 필드만 맞히고 본체는 맞히지 않음
- 궁극기: 해당 유닛 + 정해진 열쇠 캐릭터(서브 필드) + 촉매 마법
- 시너지 23종, 겸용 카드(유닛·서브) 16장
- 마허라: 항상 장착, 뽑기로 나오지 않으며 메구미 + 십종영법 식신 3종 + 생명 1개 조건에서 소환

## 온라인 대전 (GitHub PR·머지)

별도 서버 없이, 대전 기록을 이 저장소에 **PR로 올리고 머지**해서 주고받습니다.

- 방 하나 = `jjk-online` 브랜치의 `jjk_rooms/<방코드>.json` 파일 (사이트의 `main`은 건드리지 않음)
- 방 만들기·참가·**턴 종료**·나가기 때마다 게임이 자동으로 브랜치 생성 → 커밋 → PR → 스쿼시 머지 → 임시 브랜치 삭제
- 상대는 그 파일을 3초마다 읽어 반영 (바뀐 게 없으면 GitHub가 304로 응답해 사용량을 거의 쓰지 않음)
- 상대 화면에는 턴이 끝날 때 그 턴의 행동이 한꺼번에 반영됨 (5~10초)
- 두 사람이 동시에 기록하면 머지 충돌이 나고 늦은 쪽이 최신 기록을 다시 읽음 → 턴 잠금
- 턴 제한시간 150초. 상대가 응답이 없으면 시간이 지난 뒤 내 쪽에서 턴을 가져옴
- 홈의 [QR로 친구 초대]를 누르면 방이 만들어지고, 그 QR을 찍으면 게임이 열리며 그 방에 자동 참가

**필요한 것**: 두 사람 모두 GitHub 계정과 이 저장소에 쓸 수 있는 토큰이 필요합니다. 친구는 저장소 **Settings → Collaborators**에 추가해야 합니다.

**토큰 만들기**: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access: 이 저장소만 → Permissions: **Contents** 읽기·쓰기, **Pull requests** 읽기·쓰기. 토큰은 각자 기기의 브라우저에만 저장되고 저장소에는 올라가지 않습니다. 공용 기기에서는 쓰지 마세요.

**참고**: 한 판에 PR이 수십 개 생깁니다(모두 자동 머지·정리). 기록을 지우려면 `jjk-online` 브랜치를 삭제하면 됩니다.
