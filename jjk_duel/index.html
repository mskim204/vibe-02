GitHub PR 대전

GitHub 연결

대전 기록을 GitHub 저장소에 PR로 올리고 머지해서 주고받습니다. 방 만들기·참가·턴 종료 때마다 게임이 자동으로 PR을 만들고 머지합니다. 상대 화면에는 5~10초 뒤에 반영됩니다.

토큰 만드는 방법
  1. GitHub → 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 이 저장소 선택
  3. Permissions: Contents 읽기·쓰기, Pull requests 읽기·쓰기
  4. 만든 토큰(github_pat_…)을 위 칸에 붙여넣기

토큰은 이 기기에만 저장되고 저장소에는 올라가지 않습니다. 친구도 자기 계정의 토큰이 필요하며, 저장소 Settings → Collaborators에 추가되어 있어야 합니다. 공용 기기에서는 쓰지 마세요.
